# Page 11 — Team & operating model · "Four labs, one flywheel"

> Inherits `GLOBAL-INSTRUCTIONS.md`. Light theme. Act IV opener.

## Purpose

Show the organization is buildable and coherent: four interlocking labs and how work + data flow between them, on an India-HQ + global-node model.

The one idea: *Research, Applied, Assurance, and Deployment form one loop — deployment feeds the data that compounds the moat.*

## Layout

Centre: a four-node org diagram arranged as a cycle — **Research → Applied → Deployment → Assurance → (back to Research)** — with ink flow arrows and a one-line charter under each node. A thin band beneath: "India HQ · global nodes (US/EU field + research)." Kicker/title top-left. Carry bottom.

## Steps (reveal order)

**0 — Base:** kicker, title, the four nodes present, arrows undrawn.
**1 — Charters:** each node's one-line charter fades in.
**2 — The loop:** the flow arrows `drawPath` to close the cycle; the "deployment → failure-data → Assurance + Research" return path emphasised.
**3 — Footprint:** the India-HQ/global-node band; carry.

*(3 beats.)*

## Copy

- **Kicker:** `How we build · the org`
- **Title:** **Four labs, one flywheel.**
- **Nodes:**
  - **Research** — foundations: adaptation methods, world-model compression, embodied-assurance science. Publishes.
  - **Applied** — the Composer, the pipelines, beachhead delivery. Ships.
  - **Deployment** — field systems in customer environments (US/EU). Runs, and captures real-world + failure data.
  - **Assurance** — failure-data engine, safety cases, certification discipline. Gates adoption.
- **The loop:** Deployment's data compounds both Assurance (the moat) and Research (better methods). The org *is* the flywheel.
- **Footprint:** India HQ (research + engineering + build) · global nodes (US/EU field, deployment, partnerships).
- **Carry:** `the org is designed to compound, not just to ship`
