# Page 04 — The prediction · "As both ends modularize, the enabling middle is where the leverage sits"

> Inherits `GLOBAL-INSTRUCTIONS.md`. Light theme. Act I close.

## Purpose

Turn the LLM precedent into a defensible forecast for Physical AI, and dispatch the full-stack counter cleanly. This is the analytical hinge; it lands the positioning the rest of the deck builds on.

The one idea: *Physical AI's two ends will commoditize and proliferate, so the value pools in the enabling middle — the opposite of the full-stack bet.*

## Layout

Dual-track: left column = the model end (slate) with a downward "commoditizing / bifurcating" motion; right column = the embodiment end (bronze) with an outward "proliferating" motion; both resolve toward a central ink band labelled `THE ENABLING MIDDLE`. Kicker/title top-left. A bottom-right inset callout for the full-stack side-note (Figure/Tesla). Carry line at the very bottom.

**0 — Base:** kicker + title + the two empty tracks and the (dim) central band.

*(4 beats.)*

## Copy

- **Kicker:** `The prediction`
- **Title:** **Physical AI splits the same way.**
- **Model end:** The model world bifurcates — a few frontier players, a large commoditized and open tier.
- **Embodiment end:** The embodiment world proliferates — humanoids, arms, AMRs, legged, drones; many bodies, none dominant.
- **Middle:** As both ends modularise, the scarce, still-hard capability is composing them for a real application. That's where the leverage — and the durable value — pools.
- **Full-stack side-note:** **Full-stack (Figure, Tesla) is the opposite bet** — vertical integration, right only while the stack stays immature and non-modular. The LLM era already answered which way this goes.
- **Carry:** `As both ends modularize, the enabling middle is where the value — and the leverage — sits.`
