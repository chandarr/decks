# 01 — Pressure Test, Weak Joints & Evidence Tiers

**Purpose:** the founder is sharp and will attack. These are the joints that won't survive a hard question unless pre-answered. Each becomes either a main-deck "foresight" moment or a backup slide. Showing AC pre-empted these is itself the credibility proof the deck is for.

## Weak joints (attack → defensible move → where it lands)

1. **"Why doesn't NVIDIA already own the middle?"** *(highest-priority)*
   - Attack: NVIDIA has GR00T + Cosmos (models), Jetson Thor (edge), Isaac (sim/orchestration) — already assembling a Composer.
   - Defense: NVIDIA is **not neutral** (its stack locks you to its silicon; ours picks the cheapest model+body+chip that meets the budget across vendors) and has **no appetite for Assurance** (reliability, failure-data, certification, field integration are outside its GPU-selling DNA and margin model). Firsthand credibility: AC has used Jetson at the edge — poor thermal management, near-unusable in real deployment; NVIDIA ships GPUs + reference demos, not reliable products.
   - Lands: **main deck** (NVIDIA differentiation woven into the MOAT / neutrality moment) + backup detail.

2. **Business model is thin.**
   - Attack: "monetization lab" — how does it make money, and when?
   - Defense: services / forward-deployed integration (near-term cash, US/EU) → Composer licensing/subscription (platform) → Assurance/certification fees (moat rent). Must be an explicit slide, not hand-waved.
   - Lands: **main deck** (business model / roadmap). *Gap to fill — currently under-specified.*

3. **"A startup becoming a certification body" overreaches.**
   - Attack: UL/TÜV earned trust over decades, often with regulatory backing.
   - Defense: be the **technical standard-setter + safety-case tooling + failure-data engine** that existing bodies/regulators adopt; partner with TÜV/UL rather than replace them. Aspirational-tier, not year-one.
   - Lands: Assurance slide (tiered) + backup.

4. **The Composer sounds like magic.**
   - Attack: auto-generating a full stack from {requirement, budget, application} is very hard.
   - Defense: v1 = human-in-the-loop config tool over a library of validated recipes; autonomy grows with the recipe library + deployment data. Show the incremental path.
   - Lands: Composer slide (show v1 → vN) + backup.

5. **Superhuman beachhead vs. horizontal platform — real tension.**
   - Attack: mining/subsea/nuclear need deep vertical + hardware specialization, contradicting a horizontal middle-layer lab.
   - Defense: go vertical-deep on ONE beachhead first, name the tension openly, generalize the platform from what's learned.
   - Lands: Superhuman slide + roadmap.

6. **"Can you attract world-class researchers to India?"**
   - Attack: talent-draw scepticism.
   - Defense: the magnet is an under-served field (embodied Assurance/safety) where a top researcher can *own* a discipline; global remote nodes; mission + equity; India's real embedded/robotics depth. India = talent + R&D, not the market.
   - Lands: team slides.

7. **Scope — doing too much?**
   - Attack: three buckets + Composer + certification + academy + agentic execution + superhuman + environments = unfocused.
   - Defense: **evidence-tier everything** and keep tiers marked on every slide — Near-term (beachhead + Adaptation pipeline + failure-data) / Building (Autonomy flywheel + Composer v1) / Aspirational (certification authority + academy + full autonomy + intelligent environments). Focus is a feature.
   - Lands: a legend/tier motif used deck-wide + the "what breaks this" slide.

## Evidence tiers (mark consistently, all the way onto slides)
- **NEAR-TERM (proven / doable now):** Adaptation pipeline (edge orchestration, distillation, compression), failure-data capture, first superhuman beachhead, services revenue.
- **BUILDING (frontier, credible path):** Autonomy learning flywheel, Composer v1 (recipe library + config assistant), continuous-assurance tooling.
- **ASPIRATIONAL (vision, stated as such):** certification authority, full-autonomy Composer, the academy at scale, intelligent-environment orchestration.

## Deck-level implication
Add a main-deck slide: **"What breaks this — and how I'd de-risk it"** (confident foresight), with per-joint backups. This slide is a primary vehicle for the deck's true job (prove AC is the right leader).
